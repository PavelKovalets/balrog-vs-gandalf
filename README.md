# Gandalf vs Balrog — Bridge Duel Game

A turn-based battle game inspired by the Bridge of Khazad-dûm scene.

## How to run
Open `index.html` in a browser. No build step, no dependencies.

## How to play
You are Gandalf. Defeat the Balrog before it defeats you.

Each turn, choose one action:
- **Strike** — 8–12 damage
- **Fire Spell** — 18–25 damage (2-turn cooldown)
- **Shield** — block the next incoming attack
- **Light** — 50% chance to stun the Balrog

The Balrog will Whip, Smash (50% hit chance), or Rage (buffs its next attack).

When the fight ends, click **New Battle** to play again.
